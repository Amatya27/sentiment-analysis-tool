Sentiment model benchmark

Runs both models from the tool on 200 random labeled examples from each dataset, pulled live from the Hugging Face datasets API with a fixed seed. Everything runs in this tab and takes a few minutes the first time, while the models download.

  • cardiffnlp/tweet_eval (sentiment, test): tweets labeled positive, neutral or negative
  • mteb/amazon_reviews_multi (en, test): 1-2 stars = negative, 3 = neutral, 4-5 = positive
  • stanfordnlp/sst2 (validation): movie review sentences, positive or negative only
